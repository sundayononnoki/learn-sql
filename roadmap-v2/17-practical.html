本阶段知识点

查询写法

  1. AS 给列和表起别名
  2. 列别名 用派生表在 WHERE 中筛选
  3. AND / OR 用括号明确筛选范围
  4. LEFT JOIN 在 ON 里限制右表
  5. ORDER BY 用唯一键稳定取前 N 行
  6. LIKE ESCAPE 按字面查找百分号和下划线

NULL 与空白

  1. WHERE IS NULL 查缺失值
  2. NULL 安全比较 让两个缺失值相等
  3. COUNT(*) 和 COUNT(列) 区分总行数与非空数
  4. COALESCE 给 NULL 设置显示值
  5. NOT IN 遇到 NULL 时用 NOT EXISTS 查未匹配行
  6. TRIM + NULLIF 清理首尾空格并识别空白值
  7. REPLACE 清理 Tab 和不换行空格
  8. 字符数、字节数与尾随空格

数值与日期时间

  1. CAST 先转小数再相除
  2. 日期时间 WHERE 用半开区间筛整天或整月
  3. 按月分组 用月初日期作为分组键
  4. 日期格式化 在输出时转换为文本
  5. 时区转换 将东京本地时间换算为 UTC

数据同步

  1. MERGE / UPSERT 按订单号更新或插入

索引实操

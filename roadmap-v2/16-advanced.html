PostgreSQL SQL Server MySQL

合上示例试一题

哪两个排名函数对并列后的下一位处理不同？

查看答案

RANK 会跳号，DENSE_RANK 连续编号。

本阶段知识点
  1. 窗口函数 OVER 保留明细并汇总
  2. RANK 并列后跳号
  3. DENSE_RANK 并列后连续排名
  4. LEAD 读取下一行
  5. LAG 读取上一行
  6. ROW_NUMBER 组内逐行编号
  7. FIRST_VALUE 取窗口首行值
  8. 递归 CTE 逐步生成序列
  9. PIVOT / UNPIVOT 互换行与列
  10. WITH 命名中间结果
  11. 动态 SQL 绑定参数后执行

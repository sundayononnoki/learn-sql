合上示例试一题

怎样避免分母为 0 的除法？

查看答案

使用 NULLIF(分母, 0)，使分母为零时结果为 NULL。

本阶段知识点

字符串函数

  1. CONCAT 连接字符串
  2. LENGTH / LEN 测量字符串长度
  3. SUBSTRING 截取字符串
  4. REPLACE 替换文本
  5. UPPER 转为大写
  6. LOWER 转为小写

数值函数

  1. FLOOR 向下取整
  2. ABS 求绝对值
  3. MOD / % 求余数
  4. ROUND 四舍五入
  5. CEILING 向上取整

条件表达式

  1. CASE 按条件返回值
  2. NULLIF 两值相等时返回 NULL
  3. COALESCE 取第一个非空值

日期与时间

  1. DATE 仅保留日期
  2. TIME 表示时刻
  3. TIMESTAMP / datetime2 保存日期和时间
  4. DATEPART / EXTRACT 提取月份
  5. DATEADD / DATE_ADD 为日期加天数

ESCAPE 匹配字面量

MySQL

为含 % 或 _ 的数据明确写转义符。采用 ! 可避免 SQL 字符串与反斜杠的双重转义。

查看执行前的数据

文本LIKE 模式ESCAPE

50%50!%!

执行结果

SELECT 'A_1' LIKE 'A!_1' ESCAPE '!' AS literal_underscore, '50%' LIKE '50!%' ESCAPE '!' AS literal_percent;
literal_underscoreliteral_percent
11
执行说明

执行前　数据就是 A_1 和 50%，符号也是文本的一部分。

执行后　!_ 和 !% 按字面匹配，两列都为 1。

两列都为 1。

大小写、尾空格和模式位置

MySQL

LIKE 匹配整串。大小写由排序规则决定，尾空格也占一个字符的位置。

方括号通配符的方言差异

MySQL

读到 LIKE '[A-C]%' 先确认方言。SQL Server 的 LIKE 支持方括号字符集、范围和 [^...] 排除。范围成员受排序规则影响。MySQL 可用正则表达式匹配这些模式。

查看执行前的数据
模式匹配的输入
label
B2
Z2

执行结果

SELECT 'B2' LIKE '[A-C][0-9]' AS mysql_like, REGEXP_LIKE('B2', '^[A-C][0-9]$', 'c') AS in_range, REGEXP_LIKE('Z2', '^[^A-C][0-9]$', 'c') AS outside_range;
mysql_likein_rangeoutside_range
011
SQL Server 的语法对照
表达式匹配结果
'B2' LIKE '[A-C][0-9]'真
'Z2' LIKE '[^A-C][0-9]'真

Access 的 ANSI-89 模式中，* 匹配任意序列，? 匹配单字符，# 匹配数字，[!...] 排除字符。'B2' LIKE 'B#' 返回真。Access 的 ANSI-92 模式使用 % 和 _。

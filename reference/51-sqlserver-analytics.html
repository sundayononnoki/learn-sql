STRING_AGG · 组内排序再拼接

SQL ServerSQL Server 2017+ · WITHIN GROUP 需兼容级别 110+

WITHIN GROUP 的 ORDER BY 决定拼接顺序。NULL 既不参与拼接，也不产生分隔符。先把输入转成 nvarchar(max)，可避免固定宽度输出类型带来的长度限制。

查看执行前的数据
拼接输入
idlabel
1sql
2db
3NULL

预期结果

SELECT STRING_AGG(CONVERT(nvarchar(max), label), N',') WITHIN GROUP (ORDER BY id DESC) AS labels FROM (VALUES (1, N'sql'), (2, N'db'), (3, NULL)) AS t(id, label);预期结果
labels
db,sql

只使用 STRING_AGG 时可用任意兼容级别。需要去重时先在子查询去重，再拼接。

用 CASE 做条件聚合

SQL Server

条件聚合在同一组上计算多个指标。COUNT 的 CASE 省略 ELSE 时，未匹配行产生 NULL。SUM 给未匹配行 0，可以在非空分组内展示缺失类别的零值。

预期结果

SELECT COUNT(*) AS all_orders, COUNT(CASE WHEN status = 'paid' THEN 1 END) AS paid_orders, SUM(CASE WHEN status = 'paid' THEN qty ELSE 0 END) AS paid_qty, SUM(CASE WHEN status = 'canceled' THEN qty ELSE 0 END) AS canceled_qty FROM (VALUES ('paid', 4), ('paid', 2), ('pending', 3)) AS t(status, qty);预期结果
all_orderspaid_orderspaid_qtycanceled_qty
3260

整个输入为空时 SUM 返回 NULL。需要零时在聚合结果外使用 COALESCE。

CONT 按连续分布插值，DISC 返回累计分布达到该百分位的第一个输入值。两者均忽略 NULL。在 SQL Server 中两者用 WITHIN GROUP 写排序，用 OVER 指定分区。这里 SELECT DISTINCT 每个分区只保留一个结果。

ROWS 与 RANGE · 逐行还是逐个排序值

SQL Server窗口框架 · SQL Server 2012+

ROWS 按排序后的物理行数划定窗口，排序键含唯一 id 以得到稳定结果。RANGE 在 CURRENT ROW 边界包含所有排序键相同的行。带 ORDER BY 的 SUM 省略窗口框架时，本例默认是 RANGE 从分区开头到当前排序值。

WINDOW · 复用分区和排序

同一查询中的多个窗口函数可以引用命名窗口。先定义分区及排序，再由某次 OVER 补充框架。已定义的分区、排序或框架属性不能在引用处重写。

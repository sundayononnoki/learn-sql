COUNT(右表非空键) 数匹配订单；COUNT(*) 还会数外联结补出的那一行。把针对右表的筛选放进 ON，可以在筛订单时保留所有客户。

SELECT c.name, COUNT(o.order_id) AS paid_orders, COUNT(*) AS joined_rows FROM customers AS c LEFT JOIN orders AS o ON o.customer_id = c.customer_id AND o.status = 'paid' GROUP BY c.customer_id, c.name ORDER BY c.customer_id;

执行后　按 付款数/联结行数 输出 Ana 2/2, Bo 0/1, Chen 1/1, Dina 0/1。

Ana 为 2、2，Bo 为 0、1，Chen 为 1、1，Dina 为 0、1。若将状态条件移到 WHERE，Bo 和 Dina 的补空行会被过滤。

FULL OUTER JOIN 的 MySQL 写法

MySQL

全外联结保留左右两侧所有行。MySQL 8.4 的 JOIN 语法没有 FULL OUTER JOIN 子句。可以先取左联结，再用 UNION ALL 追加右侧未匹配的行。反匹配使用左侧确定非空的 ID。

WITH bookings AS (SELECT 1 AS id UNION ALL SELECT 2), arrivals AS (SELECT 2 AS id UNION ALL SELECT 3), both_sides AS ( SELECT b.id AS booked_id, a.id AS arrived_id FROM bookings AS b LEFT JOIN arrivals AS a ON b.id = a.id UNION ALL SELECT b.id, a.id FROM arrivals AS a LEFT JOIN bookings AS b ON b.id = a.id WHERE b.id IS NULL ) SELECT booked_id, arrived_id FROM both_sides ORDER BY COALESCE(booked_id, arrived_id);

在支持 FULL OUTER JOIN 的 PostgreSQL 或 SQL Server 中，同样的输入可写成 FROM bookings AS b FULL OUTER JOIN arrivals AS a ON b.id = a.id。三个结果依次是仅预订、已预订且到场、仅到场。

B-tree 适合排序和范围，Hash 适合等值

PostgreSQL

实际计划、缓冲、WAL 与序列化

PostgreSQLPostgreSQL 17+

ANALYZE 真的执行语句。BUFFERS 展示缓冲块访问，WAL 展示生成的预写日志，SERIALIZE TEXT 测量服务端结果转换且不计网络传输。TIMING OFF 关闭节点时间采集，不能关闭总执行时间的汇总，示例同时关闭 SUMMARY。TIMING OFF 不计序列化耗时，依旧输出序列化体积。Planning 和 Buffers 行随环境变化，小样本的返回数据也不能证明使用了某个索引。

查看执行前的数据
计划采样
输入选项
无表常量ANALYZE、BUFFERS、WAL、SERIALIZE TEXT

执行结果

EXPLAIN (ANALYZE, BUFFERS, WAL, SERIALIZE TEXT, TIMING OFF, SUMMARY OFF, COSTS OFF, FORMAT TEXT) SELECT 1;
QUERY PLAN
Result (actual rows=1.00 loops=1)
Serialization: output=1kB format=text

无表查询的计数很少。真实查询应区分每轮 Actual Rows 和 Loops，并结合数据量和 I/O。带写入的 ANALYZE 会写数据，可在隔离事务里测试并回滚。计划行随版本、设置与环境变化。

查看 I/O 计时开关与读计划提示

PostgreSQL

track_io_timing 打开后，计划能给出部分缓冲块访问的 I/O 时间。共享块 read 表示数据库从操作系统读取，可能命中操作系统缓存。SETTINGS 显示影响计划的非默认设置，MEMORY 在 PostgreSQL 17 起可报告规划阶段内存。

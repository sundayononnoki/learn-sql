数组包含、交集与 ANY / ALL

PostgreSQL

数组 @> 比较是否包含右侧每种元素，<@ 反向比较。&& 测是否有共同元素。ANY 和 ALL 对数组内各元素分别做指定的比较。

查看执行前的数据
比较对象
a重复的候选交集候选比较常量
{1,2,3}{2,2}{3,9}3

执行结果

WITH input(a) AS (VALUES (ARRAY[1,2,3])) SELECT a @> ARRAY[2,2] AS contains, ARRAY[2,2] <@ a AS contained, a && ARRAY[3,9] AS overlaps, a && ARRAY[8,9] AS disjoint_overlap, 3 = ANY(a) AS member, 3 > ALL(a) AS greater_than_all FROM input;

包含比较不按重复次数计数，因此只有一个 2 的数组仍包含 {2,2}。

jsonpath 过滤、存在测试与谓词匹配

jsonpath 描述文档路径。@? 判断路径有没有产出，适合带问号过滤的路径。@@ 取谓词的布尔结果。jsonb_path_query_array 可取出全部匹配项。

JSON_EXISTS、JSON_QUERY 与 JSON_VALUE

PostgreSQLPostgreSQL 17+

JSON_EXISTS 测路径有无结果。JSON_QUERY 可保留 JSON 结构和包装数组。JSON_VALUE 读取单个标量并可指定 SQL 类型。ON EMPTY 与 ON ERROR 各管一种结果。

查看执行前的数据
输入文档与门槛
docminimum
{"items":[{"sku":"A","qty":2},{"sku":"B","qty":5}]}3

执行结果

WITH t(doc) AS (VALUES ('{"items":[{"sku":"A","qty":2},{"sku":"B","qty":5}]}'::jsonb)) SELECT JSON_EXISTS(doc, '$.items[*] ? (@.qty > $minimum)' PASSING 3 AS minimum) AS has_large, JSON_QUERY(doc, '$.items[*].sku' WITH UNCONDITIONAL ARRAY WRAPPER)::text AS skus, JSON_VALUE(doc, '$.items[0].qty' RETURNING int ERROR ON ERROR) AS first_qty, JSON_VALUE(doc, '$.shipping' RETURNING int DEFAULT 0 ON EMPTY ERROR ON ERROR) AS shipping FROM t;

JSON_TABLE 按路径生成关系行

PostgreSQLPostgreSQL 17+

行路径选择每个 items 元素。COLUMNS 定义列类型、列路径和空结果策略，FOR ORDINALITY 给展开的行编号。

查看执行前的数据
待展开文档

执行结果

SELECT line_no, sku, qty FROM JSON_TABLE( '{"items":[{"sku":"A","qty":2},{"sku":"B"}]}'::jsonb, '$.items[*]' COLUMNS ( line_no FOR ORDINALITY, sku text PATH '$.sku', qty int PATH '$.qty' DEFAULT 0 ON EMPTY ) ) AS items ORDER BY line_no;

XPath 与 XMLTABLE

PostgreSQLPostgreSQL 10+ · libxml2

xpath 返回 XML 数组，xpath_exists 测是否选中节点。XMLTABLE 使用 XPath 1.0 指定行路径，再相对每个行节点提取属性或子元素。

查看执行前的数据
输入 XML 文档
xml_doc
<cart><item sku="A"><qty>2</qty></item><item sku="B"><qty>5</qty></item></cart>

执行结果

WITH input AS ( SELECT XMLPARSE(DOCUMENT '<cart><item sku="A"><qty>2</qty></item><item sku="B"><qty>5</qty></item></cart>') AS doc ) SELECT line_no, sku, qty, (xpath('/cart/item[1]/qty/text()', doc))[1]::text AS first_qty_xpath, xpath_exists('/cart/item[@sku="B"]', doc) AS has_b FROM input CROSS JOIN LATERAL XMLTABLE('/cart/item' PASSING doc COLUMNS line_no FOR ORDINALITY, sku text PATH '@sku', qty int PATH 'qty') ORDER BY line_no;

通过视图复用联结

MySQL

视图保存查询定义，会读取当前可见的基表数据，查询开销仍由实际计划决定。它与表共用库内命名空间。创建需要 CREATE VIEW 和引用列所需权限，OR REPLACE 还需 DROP。列名在视图内需唯一。此例用 INVOKER，调用者需具备相应底表权限。

更新视图与 WITH CHECK OPTION

MySQL

满足条件的简单视图可映射到基表行。WITH CHECK OPTION 拒绝让新版本的行离开视图筛选范围。GROUP BY、DISTINCT 和聚合使视图不可更新。联结和计算列有额外限制，先核对目标列以及手册中的可更新规则。

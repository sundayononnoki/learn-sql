唯一键、UPSERT 与重试

MySQL

INSERT 的唯一键冲突可走 ON DUPLICATE KEY UPDATE。重试安全取决于写入语义，重复设置同一状态通常比重复递增更容易控制。多个唯一键可能匹配不同目标，设计时先确定冲突键。

过时 · 已弃用 更新子句内的 VALUES(列) 在 26.10.0 仍能解析，并给出警告 1287。例子已采用行别名 incoming.status。用于给出待插入数据的 INSERT … VALUES (...) 仍可正常使用。

使用存储过程

存储过程把一组操作封装成可调用对象。用参数传递输入与输出，用局部变量表达过程内的中间值。

导入练习数据后，在当前 MySQL 会话执行 USE learn_sql_lab;。同页示例按顺序运行，临时表可开新连接重做，新建普通对象可换名重做。

先导入 PostgreSQL 练习数据。新会话执行 SET search_path TO sql_notes_lab;。

先导入 SQL Server 练习数据。新查询窗口连接 SQLNotesLab。

创建和调用无参过程

MySQL

过程有名字，即使没有参数也写括号。将复用的逻辑放在过程里，一次 CALL 能完成服务器端的多个步骤并减少往返。CREATE ROUTINE 与 EXECUTE 由权限控制。 MySQL 用 CALL。如果同名过程已在 SQL Server 的 dbo 下创建，可用 EXEC dbo.ch23_prices; 调用。

IN、OUT、INOUT 与 DELIMITER

MySQL

IN 是输入，OUT 是输出，INOUT 同时带入和带回值。mysql 客户端的 DELIMITER 改输入拆分边界，使 BEGIN…END 内可保留分号。

参数变化
阶段p_order@total@calls

调用后10145.001
查看 SQL 返回结果
SELECT @total AS total, @calls AS calls;
totalcalls
45.001
执行说明

执行前　调用前 @calls = 0。订单 101 明细总额 45.00。

执行后　调用后 @total = 45.00，@calls = 1。

调用后，在同一连接里读到 45.00 和 1。SELECT INTO 把金额写入 OUT 参数，带 @ 的变量属于当前会话。INVOKER 下调用者需有 EXECUTE 与读取明细的权限。默认 DEFINER 会按定义者的权限检查过程体。

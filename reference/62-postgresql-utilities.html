COMMENT ON TABLE 和 COMMENT ON COLUMN 分别保存对象与字段的说明。再次设置会替换原文，IS NULL 删除说明。用 obj_description 和 col_description 回查。

RESET 与 RESET ALL · 恢复会话参数

PostgreSQL

RESET 恢复一个参数，RESET ALL 恢复全部可重置的运行时参数。恢复目标取决于当前会话从未 SET 该参数时适用的值。配置重载可能改变它，以 pg_settings.reset_val 为准，角色、数据库或实例可能定义了不同默认值。

DISCARD SEQUENCES 与 DISCARD TEMP

PostgreSQL

DISCARD SEQUENCES 清掉本会话的序列缓存和 currval/lastval 记录。DISCARD TEMP 删除本会话的临时表。为避免清理别的练习状态，请用新开的独立连接。

lo_from_bytea 与 ALTER LARGE OBJECT OWNER TO

PostgreSQLlo_from_bytea 和 lo_get 自 PostgreSQL 9.4 起可用。

lo_from_bytea 创建大对象并返回其 OID。传入 0 可让数据库挑选可用的 OID。ALTER LARGE OBJECT 用 OID 转移所有权。执行者需要拥有该对象，并可切换为新所有者。此例应使用专用实例的练习超级用户，以便在转移所有者后仍能读取这个大对象。

基本匹配、LIKE 与大小写

MySQL

REGEXP 和 RLIKE 可用于判断匹配。REGEXP_LIKE 的模式选项 c 与 i 可明确指定大小写策略，点号默认匹配一个非换行字符。未显式给出选项时，大小写策略来自排序规则。

过时 · 不兼容 ICU 原书通过 BINARY 强制区分大小写，新版拒绝把二进制串作为正则参数。按需求改用 REGEXP_LIKE 的 c 或 i。

执行前　输入为 xSQLy、SQLX、sql。大小写选项分别为 c 和 i。

执行结果

1 · SELECT 'xSQLy' REGEXP 'SQL' AS piece, 'SQLX' RLIKE 'SQL.' AS any_char, REGEXP_LIKE('sql', 'SQL', 'c') AS is_case_sensitive, REGEXP_LIKE('sql', 'SQL', 'i') AS ignores_case;

2 · SELECT 'xSQLy' LIKE 'SQL', 'xSQLy' REGEXP 'SQL', 'xSQLy' REGEXP '^SQL$';
'xSQLy' LIKE 'SQL''xSQLy' REGEXP 'SQL''xSQLy' REGEXP '^SQL$'

执行说明

执行后　子串、点号、c、i 依次得 1,1,0,1。同串用 LIKE、无锚正则、带锚正则依次得 0,1,0。

第一条返回 1、1、0、1，第二条返回 0、1、0。需要跨行匹配点号时，查手册中的 n 选项。

分支、字符集与范围

MySQL

| 表示候选分支，括号把分支合在一起。[ABC] 选一个字符，方括号内的竖线表示字面竖线，[^ABC] 排除这些字符，[0-9] 指定范围。

执行前　三个输入为 AX2、B、Z。

执行结果

SELECT REGEXP_LIKE('AX2', '^(AX|BY)[0-9]$', 'c') AS alternation, REGEXP_LIKE('B', '^[ABC]$', 'c') AS member, REGEXP_LIKE('Z', '^[^ABC]$', 'c') AS excluded_set;
alternationmemberexcluded_set
111
执行说明

执行后　分支与数字范围匹配、选中集合、排除集合三个谓词皆为 1。

三列都为 1。

字面元字符与字符类

MySQL

点号等元字符可放进字符集合表达字面值。POSIX 字符类写作 [[:digit:]]、[[:alpha:]] 或 [[:space:]]。

执行前　输入是 v1.2、a、a b 和制表符。

执行结果

1 · SELECT 'v1.2' REGEXP '[.]' AS literal_dot, 'v1.2' REGEXP '[[:digit:]]' AS has_digit, 'a' REGEXP '[[:alpha:]]' AS has_letter, 'a b' REGEXP '[[:space:]]' AS has_space;

执行说明

执行后　字面点、数字、字母、空白四项都是 1。转义点和转义制表符也都返回 1。

第一条四列、第二条两列均为 1。使用反斜杠时，先经过 SQL 字符串解析，再经过 ICU 的模式解析。

次数与分组

MySQL

* 表示 0 次或多次，+ 至少一次，? 0 次或 1 次。花括号 {n}、{n,}、{n,m} 分别指定固定、下限和上下限。

执行前　测试字符串包括 SQL、SQLXX、SQLX、ab12、abc。

执行结果

SELECT 'SQL' REGEXP '^SQLX*$' AS zero_or_more, 'SQLXX' REGEXP '^SQLX+$' AS one_or_more, 'SQLX' REGEXP '^SQLX?$' AS optional, 'ab12' REGEXP '^[[:alpha:]]{2}[0-9]{1,3}$' AS counted, 'abc' REGEXP '^[[:alpha:]]{2,}$' AS minimum;
zero_or_moreone_or_moreoptionalcountedminimum
11111
执行说明

执行后　对应星号、加号、问号、有界次数、仅下限五种检查均为 1。

五列都为 1。

起止位置与词边界

MySQL

^ 和 $ 锚定起止。当前 MySQL 使用 ICU 的词边界 \b，普通 SQL 字符串里需写两个反斜杠（此例使用默认 SQL 模式）。

过时 · 旧正则引擎 原书的 [[:<:]] 和 [[:>:]] 属于旧引擎语法，ICU 示例用 \b。

自测

如何匹配恰好由三位 ASCII 数字组成的整串？ICU 的 \A 和 \z 表示绝对起止，末尾换行同样会被拒绝。

值

a123

执行结果

SELECT '123' REGEXP '\\A[0-9]{3}\\z', 'a123' REGEXP '\\A[0-9]{3}\\z';
'123' REGEXP '\\A[0-9]{3}\\z''a123' REGEXP '\\A[0-9]{3}\\z'
10
执行说明

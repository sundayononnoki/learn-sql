PostgreSQL · 聚合、窗口与集合函数

用聚合生成分组统计，用窗口保留原行并计算上下文，用集合函数生成日历和下标。各例都给出可独立复制的数据和结果。

FILTER 为每个聚合选择输入行

PostgreSQLPostgreSQL 9.4+

FILTER 只影响它前面的聚合函数。这里同一批订单既计算总行数，也计算已付款笔数与金额。空输入时 COUNT 为 0，SUM 为 NULL。需要金额默认零时可用 COALESCE。

WITH sales(order_id, status, amount) AS ( VALUES (1, 'paid', 20), (2, 'pending', 30), (3, 'paid', 10) ) SELECT COUNT(*) AS all_orders, COUNT(*) FILTER (WHERE status = 'paid') AS paid_orders, SUM(amount) FILTER (WHERE status = 'paid') AS paid_total FROM sales;

GROUPING SETS 与 GROUPING()

PostgreSQLPostgreSQL 9.5+

为地区小计、品类小计和总计分别指定分组键。空括号 () 表示总计。GROUPING 中参数未参与当前分组时对应位为 1，最右参数是最低位。看 region_omitted 可区分原始值为 NULL 的地区与省略地区维度。

PostgreSQLPostgreSQL 9.5+

ARRAY_AGG、STRING_AGG 与聚合内部排序去重

PostgreSQLPostgreSQL 9.0+

把 ORDER BY 写在聚合参数内可固定元素顺序。用 DISTINCT 时，排序项必须出现在 DISTINCT 参数中。ARRAY_AGG 可保留 NULL 元素，STRING_AGG 跳过 NULL 文本，分隔符写在排序子句之前。

WITH sample(id, name, price) AS (VALUES (1,'Ana',20), (2,'Bo',30), (3,NULL,30)) SELECT array_agg(DISTINCT price ORDER BY price DESC)::text AS prices, array_agg(name ORDER BY id)::text AS names_with_null, string_agg(name, ', ' ORDER BY id DESC) AS names_text FROM sample;

WINDOW 定义与复用

PostgreSQL

用 WINDOW 给分区和排序命名，OVER 可引用定义。此处每位客户的总额按分区计算，累计额使用同一分区和明确的行框架。窗口保留原行数。窗口内排序决定计算次序，最外层 ORDER BY 决定展示顺序。

ROWS、RANGE 和 GROUPS 窗口框架

PostgreSQLPostgreSQL 11+

ROWS 按窗口排序后的行位置移动，这里用 id 将并列行固定顺序。带偏移的 RANGE 按单个排序值的距离扩展行集。GROUPS 按并列排序键形成的组移动。取累计值时，不显式写框架会默认包含当前排序键的其它并列行。

EXCLUDE 排除当前行或同组并列行

PostgreSQLPostgreSQL 11+

在指定框架内，EXCLUDE CURRENT ROW 排除当前行，EXCLUDE GROUP 排除当前行及同排序键的其它行，EXCLUDE TIES 只排除其它并列行。EXCLUDE NO OTHERS 保留整个框架，也是默认值。

窗口函数的 IGNORE NULLS 与 RESPECT NULLS

PostgreSQLPostgreSQL 19+

默认 RESPECT NULLS 把空值所在行也纳入位置计算。IGNORE NULLS 为 lag、lead、first_value、last_value 和 nth_value 跳过值为空的行。first、last 与 nth 在窗口框架内取值，lag 与 lead 沿整个分区查找。用 last_value 和从起点到当前行的框架可向前填充。

按时区生成跨夏令时的日历序列

PostgreSQLPostgreSQL 16+（第四个时区参数）

带时区版本可指定解释日历步长所用的时区。因此连续两个本地午夜相隔的实际时长会随夏令时变化。输出同时格式化为纽约本地时间和 UTC，避免会话时区影响展示。

generate_subscripts 按真实数组下标展开

函数读取指定维度的合法下标，空值元素也有下标。第三个参数 true 逆序输出下标。WITH ORDINALITY 另外从 1 数输出位置，输出位置与数组下标可以不同。数组没有所给维度时返回零行。

LEFT JOIN LATERAL · 在子查询中引用当前行

PostgreSQL

右侧子查询可引用左侧的客户，此处按订单编号取最大的一笔。LEFT JOIN 保留没有订单的客户，并把右侧结果补成 NULL。

WITH orders(customer_id, order_id) AS (VALUES (1, 101), (1, 102)) SELECT c.customer_id, latest.order_id FROM (VALUES (1), (2)) AS c(customer_id) LEFT JOIN LATERAL ( SELECT order_id FROM orders WHERE customer_id = c.customer_id ORDER BY order_id DESC LIMIT 1 ) AS latest ON true ORDER BY c.customer_id;

JSONB · 按结构匹配并更新字段

PostgreSQL

用 @> 检查 JSON 结构是否包含所给键值。用 jsonb_set 替换指定路径，返回新 JSONB。这里在 SELECT 中计算，来源行没有写入。

查看执行前的数据
来源文档
doc
{"active":true,"qty":2}

执行结果

WITH src(doc) AS (VALUES ('{"active":true,"qty":2}'::jsonb)) SELECT doc @> '{"active":true}'::jsonb AS is_active, (jsonb_set(doc, '{qty}', '3'::jsonb) ->> 'qty')::int AS next_qty FROM src;

CTE MATERIALIZED / NOT MATERIALIZED · 控制折叠

PostgreSQLPostgreSQL 12+

MATERIALIZED 建立优化屏障。对无副作用 CTE，NOT MATERIALIZED 允许与外层一起优化，重复引用时可能重复计算。两写法的数据结果一致。递归或含 VOLATILE 调用的 CTE 不会被 NOT MATERIALIZED 折叠。

查看执行前的数据
输入

执行结果

WITH base(id,qty) AS (VALUES (1,5),(2,8)), m AS MATERIALIZED (SELECT * FROM base), inline AS NOT MATERIALIZED (SELECT * FROM base) SELECT m.id,m.qty AS materialized,inline.qty AS folded FROM m JOIN inline USING (id) WHERE m.id=2;

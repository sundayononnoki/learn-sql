ILIKE 与 SIMILAR TO

PostgreSQL

ILIKE 按正在使用的区域设置忽略大小写。SIMILAR TO 匹配整串，支持 LIKE 的 % 和 _，也支持 (A|B) 这样的分支。点在 SIMILAR TO 的模式中是普通字符。

~、~*、!~ 与 !~*

PostgreSQL

~ 区分大小写，~* 忽略大小写。带 ! 的变体对匹配结果取反。POSIX 正则可在字符串中寻找子串，^ 和 $ 把匹配限制在起点和终点。

regexp_match 与 regexp_matches 返回捕获组

PostgreSQLregexp_match 自 PostgreSQL 10 起可用；WITH ORDINALITY 自 9.4 起可用。

regexp_match 返回首次匹配的捕获组数组。regexp_matches 带 g 返回每一次匹配，结果每次一行。匹配不存在时，前者给 NULL，后者给零行。例中 WITH ORDINALITY 保留匹配序号。

查看执行前的数据
待拆的标签
文本捕获模式

执行结果

WITH src(value, pattern) AS (VALUES ('book:12 pen:3','([a-z]+):([0-9]+)')) SELECT n AS match_no, parts[1] AS label, parts[2]::int AS qty, (regexp_match(value, pattern))[1] AS first_label FROM src CROSS JOIN LATERAL regexp_matches(value, pattern, 'g') WITH ORDINALITY AS matches(parts,n) ORDER BY n;

2pen3book

regexp_match 与 regexp_matches 在没有捕获括号时会返回整个命中串。

PostgreSQL带起点和匹配序号的 regexp_replace 重载自 PostgreSQL 15 起可用。

默认只替换第一次，g 将全部替换。带起点和第 N 次参数的变体可选择其中一次。替换串里的反向引用能复用匹配的捕获组。

PostgreSQL^@ 和 starts_with 自 PostgreSQL 11 起可用。

date_add 与 date_subtract 采用指定时区的日历

PostgreSQLdate_add 与 date_subtract 自 PostgreSQL 16 起可用。

以纽约的夏令时切换为例。按日历加一天保持本地正午，实际只过 23 小时。若加固定 24 小时，本地时间变成下午 1 点。date_subtract 使用同一时区规则往回算。

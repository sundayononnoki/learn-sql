客户端与服务器

区分服务器、客户端和 SQL。能在命令行连接服务，获取版本并选择适合自己的工具。

客户端与服务器

MySQL

MySQL 服务器进程 mysqld 管理数据并执行 SQL。客户端 mysql 可经本地 socket 或 TCP 发送请求，适合逐条执行和导入脚本。

执行前　终端未连接，本机 MySQL 服务已启动。

执行结果

1 · mysql -u root -p
终端状态认证成功后
已连接mysql>
执行说明

执行后　正确输入账号密码后出现 mysql>。

执行前　客户端已连接并由服务器匹配到授权账号。

执行结果

SELECT CONNECTION_ID(), CURRENT_USER();示例输出
CONNECTION_ID()CURRENT_USER()
15root@localhost
执行说明

执行后　例如 连接 ID = 17、CURRENT_USER() = root@localhost，两值随实际连接而变。

把 root 换成自己的练习账号。已启动本地服务器并具备相应凭据时，输入密码后出现提示符。SQL 返回当前连接编号和用于权限检查的账户。

服务器版本与客户端版本

MySQL

终端里查到的是客户端版本。通过 SQL 可以确认当前连接的服务器版本。版本背景可帮助读旧例。4.x 引入 UNION 和事务支持，4.1 增加子查询，5.x 引入视图、存储过程、触发器和游标。入门优先使用 9.7.4 LTS。已有 8.4 LTS 环境也可运行基础练习。查看当前发布版本与精确版本查询。

执行前　操作系统能找到本机 mysql 可执行文件。

执行结果

1 · mysql --version版本示例
程序客户端版本
mysql9.7.4
执行说明

执行后　终端打印客户端版本，例如 mysql Ver 9.7.4。

执行前　已连接 MySQL 9.7.4 实例。

执行结果

SELECT VERSION() AS server_version;示例输出
server_version
9.7.4
执行说明

执行后　server_version = 9.7.4。

两处各显示自身版本。例如连接 9.7.4 LTS 时显示 9.7.4。

mysql 命令行操作

MySQL

用 ; 或 \g 发送查询。查询输入一半时可用 \c 取消本次输入，help SELECT 查询服务端帮助，quit 退出客户端。

执行前　已进入 mysql>，输入缓冲区为空。

执行结果

SELECT 1
1
1
\c / help SELECT / quit客户端命令
客户端命令状态
\c先前输入未发送
help SELECT已加载帮助表时显示 SELECT 帮助
quit退出
执行说明

执行后　输入 SELECT 999 后先用 \c 清空缓冲区。下一条查询返回 1。帮助表可用时显示 SELECT 帮助，随后退出客户端。

取消输入 999 后，查询只返回一行 1。若服务器已加载帮助表，会显示 SELECT 帮助，随后退出。

图形查询与管理工具

MySQL

Workbench 的 SQL Editor 可打开 setup.sql 执行并刷新 Schemas。该工具主要在 MySQL 8.0 上开发和测试，连接 8.4 及更高版本时部分功能可能受限。页首上手指南使用 mysql 命令行。

过时 · 停止维护 原书的 MySQL Administrator 与 MySQL Query Browser 属于旧 GUI Tools Bundle。Oracle 旧工具归档说明。

执行前　SQL Editor 已连接服务器，但尚未选库。

执行结果

SELECT DATABASE() AS active_schema, VERSION() AS server_version;示例输出
active_schemaserver_version
NULL9.7.4
执行说明

执行后　active_schema = NULL。服务器版本例如 9.7.4。

在 SQL Editor 中运行，显示当前默认数据库与服务器版本。刚连接且未选库时，数据库列为 NULL。

索引附属于表。它可能降低读取成本，也增加写入与存储成本。这里表很小，查询返回同一行，数据库是否选择索引要看计划。

做完后自测

在视图结果里新增一列，会自动在底表新增列吗？

核对答案

普通视图保存查询定义。增加投影列要修改视图定义，底表结构由 ALTER TABLE 管理。

如果实际结果和笔记不同，记下数据库版本、SQL 和错误提示，再来问我。

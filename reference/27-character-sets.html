在表与列上显式制定比较规则

MySQL

使用 CHARACTER SET 与 COLLATE 定义表默认值或针对列覆盖。表改变默认规则会影响未来列，转换已有文字列使用 CONVERT TO 并验证数据及唯一键。连接问题可从客户端的 --default-character-set=utf8mb4 参数查起。

执行前　当前会话尚无 ch27_keys。本段会建一列区分大小写的 word，并插入 SQL。

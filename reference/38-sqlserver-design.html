SQL Server · 历史版本、并发与索引

数据库保留行历史，用版本值检查并发，再用计算列和筛选索引表达可维护的查询结构。 临时表示例重复运行时请开新连接。

FOR SYSTEM_TIME · 读取系统维护的历史版本

SQL ServerSQL Server 2016+

先连接专用 SQLNotesLab，确认当前没有事务、两张同名表尚未创建。整段按自动提交模式首次运行，建表后会保留演示表和历史表。插入与更新分开提交，创建两个有效期间。历史时间由系统按 UTC 记录，本例只投影稳定的业务值。

rowversion · 检测读后写之前的并发变更

SQL Server

rowversion 是数据库自动生成的二进制版本值。用读取时的版本与当前版本一起定位写入行。本例先模拟一次别的写入，再用旧版本尝试更新，影响行数为 0。

使用触发器

触发器跟随 INSERT、UPDATE、DELETE 事件逐行执行，用 NEW 和 OLD 读取变更前后值。

导入练习数据后，在当前 MySQL 会话执行 USE learn_sql_lab;。同页示例按顺序运行，临时表可开新连接重做，新建普通对象可换名重做。

先导入 PostgreSQL 练习数据。新会话执行 SET search_path TO sql_notes_lab;。

先导入 SQL Server 练习数据。新查询窗口连接 SQLNotesLab。

INSERT 触发器：访问 NEW

MySQL

BEFORE 可校正 NEW，自动生成的 NEW.id 此时为 0。AFTER 可记录已分配的自增 ID。触发器定义在普通表上，名字在库内唯一，创建需有 TRIGGER 权限。每条受影响的行触发一次。示例先创建独立表。

MySQL

检查、顺序与移除

MySQL

多语句校验和变更失败

MySQL

BEGIN…END 里可以做多步校验。触发器以定义者上下文执行，不自行提交事务。可调用符合触发器限制的过程，例如不向客户端返回结果集、无动态 SQL 的过程。

触发器的行级与语句级处理

PostgreSQLSQL Server

PostgreSQL 可设 FOR EACH ROW，用 OLD / NEW 比较一行。SQL Server 的 DML 触发器按语句执行，inserted / deleted 是一批行，本例用更新中保持不变的唯一键 id 配对旧行和新行。一条 UPDATE 修改两行，日志也应有两行。首次运行时，练习库内这两张新表应尚未创建。

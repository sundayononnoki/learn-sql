bit、money 与 decimal

SQL Server

bit 只有 0、1 和 NULL。转成 bit 时任何非零数都归为 1。SUM 前可把 bit 转为 int。money 固定四位小数，涉及四舍五入和多步金额运算时宜用业务指定精度的 decimal。

OPENROWSET 与 OPENDATASOURCE 的临时连接

SQL Server受支持的 Windows SQL Server 提供程序情景。有效身份需要能够认证到远端，查询还受实例 Ad Hoc Distributed Queries 与提供程序 DisallowAdhocAccess 设置约束。

临时提供程序访问适合偶发且经部署批准的读取。OPENROWSET 接收远端查询。OPENDATASOURCE 充当临时四段名的首段。两者与读取服务器文件的 OPENROWSET(BULK) 是不同入口。本例需注册 OLE DB Driver 19，信任远端证书且配置 Windows 身份委派。两个接口在给定数据上返回相同行。

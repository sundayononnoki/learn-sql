SET LANGUAGE 与 SET DATEFORMAT

SQL Server

LANGUAGE 设置会话的语言并设定默认日期顺序。之后的 DATEFORMAT 可覆盖日期字符串解析顺序。下例使用 dmy 将日期文本读为 4 月 3 日，再按 style 23 固定输出。

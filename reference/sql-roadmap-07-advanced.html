PIVOT / UNPIVOT · 状态的行列转换

执行位置 PostgreSQL SQL 查询窗口或 psql 提示符
前提 已准备练习数据并连接到 postgres（含 sql_notes_lab 模式）。

WITH totals AS ( SELECT COUNT(CASE WHEN status = 'paid' THEN 1 END) AS paid, COUNT(CASE WHEN status = 'pending' THEN 1 END) AS pending FROM sql_notes_lab.orders ) SELECT 'paid' AS status, paid AS order_count FROM totals UNION ALL SELECT 'pending', pending FROM totals ORDER BY status;预期结果
statusorder_count
paid3
pending1

执行位置 MySQL SQL 查询窗口或 mysql 提示符
前提 已准备练习数据并连接到 learn_sql_lab。

WITH totals AS ( SELECT COUNT(CASE WHEN status = 'paid' THEN 1 END) AS paid, COUNT(CASE WHEN status = 'pending' THEN 1 END) AS pending FROM orders ) SELECT 'paid' AS status, paid AS order_count FROM totals UNION ALL SELECT 'pending', pending FROM totals ORDER BY status;预期结果
statusorder_count
paid3
pending1

执行位置 SQL Server SQL 查询窗口
前提 已准备练习数据并连接到 SQLNotesLab。

WITH totals AS ( SELECT [paid], [pending] FROM (SELECT status, order_id FROM dbo.orders) AS src PIVOT (COUNT(order_id) FOR status IN ([paid], [pending])) AS p ) SELECT status, order_count FROM totals UNPIVOT (order_count FOR status IN ([paid], [pending])) AS u ORDER BY status;预期结果
statusorder_count
paid3
pending1

第一条把状态变成两列，得到 paid = 3、pending = 1。第二条把两列展开为行。MySQL 和 PostgreSQL 基础写法用条件聚合与 UNION ALL。SQL Server 支持 PIVOT 和 UNPIVOT。

做完后自测

两行在排序值上并列第一，第三行用 RANK 与 DENSE_RANK 会分别得到什么？

核对答案

RANK 得 3，DENSE_RANK 得 2。两者都给并列行相同名次，只有 RANK 留空位。

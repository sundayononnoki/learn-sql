表级主键与外键

MySQL

组合主键在表级声明，外键引用父表的键。引用父表主键或完整的唯一键。表级约束写法可在 8.4 和新版使用。对比列内 REFERENCES 在 8.4 和 9.0 之后的行为。

过时 · 已弃用 非唯一索引或部分索引键作为父键属于旧的非标准用法，8.4 起默认拒绝新建。查当前外键规则。

执行前　父表 ch21_tasks 已存在，尚无标签表。

引擎选择

MySQL

InnoDB 支持事务和外键，适合大多数应用表。MyISAM 属于非事务引擎，MEMORY 的数据在重启后丢失。一次查询可读不同引擎的表，写入时要分别了解保证。外键要求父子表使用相同引擎。InnoDB 也支持 FULLTEXT，见第 18 章。

执行前　任务表声明了 ENGINE=InnoDB。

MySQL

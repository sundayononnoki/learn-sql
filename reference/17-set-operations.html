执行前　两个分支有一个共同编号 1。

两条查询各有 6 行，编号 1 两次。第一条重复行取值相同，第二条的来源标签不同。结果列名取自第一个 SELECT。

整体排序与分支限量

MySQL

最后的 ORDER BY 或 LIMIT 作用于合并结果。若要分支自己排序和限量，给分支加括号。使用第一分支给出的结果列名作为最终排序名。

(SELECT product_id AS id FROM products ORDER BY price ASC, product_id LIMIT 1) UNION ALL (SELECT product_id FROM products ORDER BY price DESC, product_id LIMIT 1) ORDER BY id;

执行说明

执行前　最便宜的商品是 4。最贵是 2、5 并列。

执行后　两分支限量选 4 和 2，最终按 id 升序为 [2,4]。

最便宜选 4，最贵并列取 2。最终按 id 显示 2、4。

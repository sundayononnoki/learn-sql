SQL Server

编辑距离与 Jaro-Winkler 相似度

SQL ServerSQL Server 2025 CU11 起正式可用 · 早期 2025 版本属于预览

EDIT_DISTANCE 计编辑次数，可设置最大可接受距离。EDIT_DISTANCE_SIMILARITY 和 JARO_WINKLER_SIMILARITY 返回 0 至 100 的整数。JARO_WINKLER_DISTANCE 给 0 至 1 的距离，较近时值较小且同前缀权重高。显式指定受支持的 Windows 排序规则，避免默认非二进制 SQL_* 排序规则。

查看执行前的数据
近似比较输入

预期结果

OUTER APPLY · 按客户读取最近一笔订单

SQL Server

APPLY 的右侧可引用当前左行。OUTER APPLY 保留右侧没有结果的客户。本例约定订单号越大越新。业务有下单时间时，通常先按时间降序，再按唯一编号降序。把 OUTER 改成 CROSS 后，客户 2 会从结果消失。

预期结果

SELECT c.customer_id, latest.order_id FROM (VALUES (1), (2)) AS c(customer_id) OUTER APPLY ( SELECT TOP (1) o.order_id FROM (VALUES (1, 101), (1, 102)) AS o(customer_id, order_id) WHERE o.customer_id = c.customer_id ORDER BY o.order_id DESC ) AS latest ORDER BY c.customer_id;预期结果

PIVOT · 把状态变成列

SQL Server

输入仅保留分组、转列、被聚合的三列。IN 列出结果中要生成的状态列。有状态行但全为 NULL，或某个分组根本没有该状态，都可能让 SUM 得到 NULL。

查看执行前的数据
来源数据
batch_idstatusamount
1paid10
1paid20
1pending5
2paid2

预期结果

SELECT batch_id, [paid], [pending] FROM (VALUES (1, 'paid', 10), (1, 'paid', 20), (1, 'pending', 5), (2, 'paid', 2) ) AS src(batch_id, status, amount) PIVOT (SUM(amount) FOR status IN ([paid], [pending])) AS totals ORDER BY batch_id;预期结果

OFFSET/FETCH · 先规定 NULL 位置再分页

排序时用 CASE 把缺失值放在后面，再按分数与唯一 id 确定完整顺序。OFFSET 跳过第一条，FETCH 读取后一条。

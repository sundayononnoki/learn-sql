MySQL

SET 里的赋值用逗号分开。可使用旧值计算新值，也可给允许为空的列赋 NULL。UPDATE 省略 WHERE 时会选择全表。

清空表与事务

MySQL

在隔离练习表中观察 TRUNCATE 语法。TRUNCATE 是 DDL，会隐式提交，无法由用户 ROLLBACK 撤销。它重置自增计数、不会调用 DELETE 触发器，并受外键限制。需要可回滚的整表清理时，针对 InnoDB 选事务内的 DELETE。

ONLINE、RESUMABLE、低优先级与压缩

SQL ServerSQL Server 2017+ 可续跑重建，2019+ 可续跑创建 · SQL Server 2025 Enterprise 或 Enterprise Developer · 无外层事务

重建和重新组织具有不同的锁、空间和日志开销。ONLINE 仍要在特定阶段取得锁，低优先级等待的 SELF 只结束当前维护请求。RESUMABLE 支持查询运行或暂停状态以及 PAUSE、RESUME、ABORT。小表在无阻塞时应立即完成。PAGE 压缩适用于行存，读写收益需实测。

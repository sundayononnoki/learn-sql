省略有默认值、可空或自增的列

MySQL

列名和 VALUES 的位置一一配对。省略列可取得默认值，允许 NULL 且没有其它默认规则时取 NULL，自增列可由服务器生成。严格模式下，省略没有默认值的必填列会报错。

批量 VALUES

MySQL

多个元组以逗号分隔，在一条语句中完成多行写入，能减少来回通信。LOW_PRIORITY 是表级锁引擎的选项，在 InnoDB 上不改变写入优先级。

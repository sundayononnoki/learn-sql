创建账号与主机范围

MySQL

CREATE USER 建账号，再单独授权。省略主机部分会默认用 %，应显式收紧连接来源。RANDOM PASSWORD 让服务器生成口令，妥善保管返回值。这里限制 localhost 并锁定账号，先演练授权状态。

过时 · 已弃用 账号主机部分的 % 和 _ 通配符已弃用。新账号显式写允许的主机、IP 或 IPv4 网段。账号名称规则。

改密、重命名与移除

MySQL

通过 ALTER USER 改密。RENAME USER 改账户名，DROP USER 移除账号。改名和移除前应检查以该账号为 DEFINER 的对象。

过时 · 已移除 PASSWORD()、IDENTIFIED BY PASSWORD 和用 GRANT 创建账号的写法已在 8.0 移除。用 CREATE USER 建账号，再单独 GRANT。MySQL 8.0 认证变更。

过时 · 已移除 服务端 mysql_native_password 在 8.4 默认禁用，9.0 起移除。升级前，把使用旧插件的账号改为 caching_sha2_password，再用兼容客户端验证登录。新写法可用 ALTER USER '账号'@'主机' IDENTIFIED WITH caching_sha2_password BY RANDOM PASSWORD;。MySQL 认证插件说明。

GROUP BY 决定每行代表什么

MySQL

GROUP BY 后的值组合决定分组。多个 NULL 会归为一组。以默认的 ONLY_FULL_GROUP_BY 为准，优先选择分组列、聚合表达式，或与分组键有可证明函数依赖的列。

WHERE 筛行，HAVING 筛组

MySQL

WHERE 先筛原始行，HAVING 后筛聚合结果。MySQL 允许 HAVING 引用 SELECT 别名。最终顺序由 ORDER BY 指定。

查看执行前的数据
products · 练习数据
product_idcategoryprice
1book20.00
2book30.00
3stationery10.00
4stationery5.00
5book30.00

执行结果

SELECT category, COUNT(*) AS n FROM products WHERE price >= 20 GROUP BY category HAVING n >= 2 ORDER BY n DESC, category LIMIT 1;
categoryn
book3
执行说明

执行前　符合 price >= 20 的是三个图书商品，文具均未通过 WHERE。

执行后　分组并筛组后仅有 book | 3。

返回 book、3。书写顺序为 SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT。可先按 FROM/WHERE 理解输入，再跟踪汇总和输出。

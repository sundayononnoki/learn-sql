SQL ServerSQL Server 2016+ · 使用一致的历史表结构 · 本例当前表为空，读历史表需相应权限

FROM TO、BETWEEN 与 CONTAINED IN

SQL ServerSQL Server 2016+ · 同时使用当前表与历史表的相应权限

rowversion 检查乐观并发

SQL ServerSQL Server · 同一批次模拟两个客户端读到同一标记

rowversion 是数据库内产生的 8 字节变更标记。客户端读取主键及标记，回写时一并放在 WHERE 里。第一个写入更新标记，第二个写入仍携带旧标记，因此匹配零行。应用收到零行后重读并决定如何解决冲突。rowversion 的旧类型名称是 timestamp。

Change Tracking 与 CHANGETABLE

SQL ServerSQL Server 2012+（本例使用 ALTER DATABASE CURRENT） · 仅在隔离库启用 · 读取需主键列 SELECT 和 VIEW CHANGE TRACKING

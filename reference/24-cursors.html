声明、打开、读取与关闭

MySQL

存储程序的 MySQL 游标只读、只能前进，服务器可选择是否拷贝查询结果。DECLARE 定义查询，OPEN 时执行。CLOSE 后可再次打开，退出声明的 BEGIN…END 时也会自动关闭。先声明变量，再声明游标，最后声明处理器。FETCH 的目标变量和查询列数要对应。

执行说明

执行前　订单 101 的两条明细数量为 2、1。过程初始累加值为 0。

执行后　FETCH 取 2 和 1，读尽后关闭游标，@total = 3。

OPEN 后逐行得到数量 2、1。下一次 FETCH 触发 NOT FOUND，处理器置位，跳出并关闭游标，@total 得 3。必须先判断 done 再处理数据。无行的 SELECT INTO 也可能触发 NOT FOUND，复杂过程应限制处理器作用域。

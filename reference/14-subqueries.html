使用子查询

子查询把一个查询的结果传给另一个查询。观察内查询返回单值、值集合还是一张派生表。派生表例见现代 SQL 补充。

导入练习数据后，在当前 MySQL 会话执行 USE learn_sql_lab;。同页示例按顺序运行，临时表可开新连接重做，新建普通对象可换名重做。

ANY、SOME 与 ALL

MySQL

比较符 ANY (子查询) 要求至少一次比较为真，SOME 是同义词。ALL 要求每一次都为真。右侧为单列子查询时，x = ANY (子查询) 等价于 x IN (子查询)。

空子查询时 ANY 为假、ALL 为真。结果包含 NULL 时，若其他比较都无法决定真假，谓词结果可能是 NULL。

方括号允许保留字和特殊字符成为标识符。标识符内的右方括号写两次。QUOTED_IDENTIFIER ON 让双引号包裹标识符，字符串仍写单引号。该选项在解析阶段生效，创建过程时会保存设置。

@@ROWCOUNT 与 @@ERROR

SQL Server

这组 @@ 名称是系统函数。@@ROWCOUNT 反映最近语句影响或读取的行数，@@ERROR 反映上一条 T-SQL 语句的错误号。用同一条语句立刻保存或查看所需状态，避免被后续语句更新。

类型优先级改变 + 的含义

SQL Server

混合数据类型的运算中，通常把低优先级的一侧转换成较高优先级类型。int 比 varchar 优先，所以第一列表达式做加法。显式转成同类字符后，第二列表达式拼接字符串。

PostgreSQL 官方文档

RETURNING 同时返回 OLD 与 NEW

PostgreSQLPostgreSQL 18+

18 开始可在 DML RETURNING 直接引用 OLD、NEW，并可为它们改名。UPDATE 有前后两份行，普通 INSERT 没有旧行，DELETE 没有新行。需要读取旧版 UPDATE 前值时，可在同一事务先锁行、取值，再 UPDATE ... RETURNING。

WITHOUT OVERLAPS 与 PERIOD 按时间覆盖做约束

PostgreSQLPostgreSQL 18+

18 原生时间约束用 range 或 multirange 表达区段。WITHOUT OVERLAPS 要求相同 stream 的区段不相交。PERIOD 外键要求该 stream 的父行共同覆盖整个子区段。示例用两个内置范围类型，让 GiST 同时支持等值键和重叠检测。

INSERT INTO pg49_child VALUES ('[1,2)', '[2026-01-15,2026-02-15)') RETURNING lower(valid_on) AS starts_on, upper(valid_on) AS ends_before;

旧版可用 EXCLUDE 禁止重叠，跨多行的时间覆盖还要另行保证。普通键与范围组合可能需要 btree_gist 来支持普通键的 GiST 等值运算。

ON CONFLICT DO SELECT 读取既有行

PostgreSQLPostgreSQL 19+

19 在冲突分支读取而无需触发实际 UPDATE，语句须包含 RETURNING。若键 1 已有原值，提议改写的值不会被写入。需继续在事务中操作时，可在 DO SELECT 后显式指定 FOR UPDATE 等行锁。

COPY TO 直接输出 JSON 数组

PostgreSQLPostgreSQL 19+

19 的 COPY TO 支持 FORMAT JSON。FORCE_ARRAY 将整个流包成一个有序 JSON 数组。用 TO STDOUT 在 psql 中观察数据，不需要服务器文件路径。

查看执行前的数据
查询两行
id
1
2

执行结果

COPY (SELECT id FROM (VALUES (2), (1)) AS src(id) ORDER BY id) TO STDOUT WITH (FORMAT JSON, FORCE_ARRAY);
标准输出（合并换行展示）
[{"id":1},{"id":2}]

真实流含换行。旧版可用 json_agg(id ORDER BY id) 输出单值。如需相同对象形状，用 json_agg(json_build_object('id', id) ORDER BY id)。

在事务开头指定隔离级别与访问模式

PostgreSQL

SET TRANSACTION 在该事务的第一个查询或数据修改前执行。READ COMMITTED 每条命令取自己的快照。REPEATABLE READ 与 SERIALIZABLE 复用事务快照。SERIALIZABLE READ ONLY DEFERRABLE 可能先等待安全快照，适合长时间只读核对。READ UNCOMMITTED 在 PostgreSQL 按 READ COMMITTED 处理。

选择四种行锁强度

PostgreSQL

FOR UPDATE 最强。FOR NO KEY UPDATE 允许别的事务取 KEY SHARE。FOR SHARE 为共享锁，会阻止数据更新。FOR KEY SHARE 阻止删除和修改可用于外键的键，却可与不改变键的普通 UPDATE 并存。

NOWAIT 立即失败，SKIP LOCKED 跳过被锁行

PostgreSQL

在同一练习库打开 A、B。A 保持事务开启。B 保持自动提交，先运行预期失败的 NOWAIT，再运行 SKIP LOCKED。后者适合多个工作进程取待办任务，所得行集受锁影响。请按面板顺序在指定连接分别执行。

MERGE · 条件优先级、DELETE 和 DO NOTHING

一个候选行只执行首个满足条件的 WHEN。本例优先删除已废弃项，再更新改量项。没有变化的匹配行进入 DO NOTHING。返回删除动作时取目标旧值。

WITH changed AS ( MERGE INTO pg_merge_rules AS t USING (VALUES (1,7,false),(2,8,false),(3,2,true)) AS s(id,qty,obsolete) ON t.id = s.id WHEN MATCHED AND s.obsolete THEN DELETE WHEN MATCHED AND t.qty IS DISTINCT FROM s.qty THEN UPDATE SET qty = s.qty WHEN MATCHED THEN DO NOTHING RETURNING merge_action() AS action, t.id, t.qty ) SELECT action,id,qty FROM changed ORDER BY id;

MERGE · 用 GROUP BY 整理重复来源

PostgreSQLPostgreSQL 17+

多条来源记录匹配并试图改同一目标行会报错。先按业务键确定规则。这里把各渠道发来的增量求和，再合并。

MERGE INTO pg_merge_delta AS t USING ( SELECT id, SUM(delta)::int AS delta FROM (VALUES (1,2),(1,3)) AS v(id,delta) GROUP BY id ) AS s ON t.id = s.id WHEN MATCHED THEN UPDATE SET qty = t.qty + s.delta RETURNING t.id,t.qty;

这是累加操作。同一批来源重放会再次累加，重试幂等需要另存事件编号。

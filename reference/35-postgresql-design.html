daterange 与 && · 检查时间窗口重叠

PostgreSQL

这里使用左闭右开区间 [开始, 结束)。两个区间仅在边界相接时不重叠，适合表达可连续预订的日期。

WITH requests(id, stay) AS (VALUES (1, daterange('2026-06-02', '2026-06-04', '[)')), (2, daterange('2026-06-03', '2026-06-04', '[)')) ) SELECT id, stay && daterange('2026-06-01', '2026-06-03', '[)') AS overlaps FROM requests ORDER BY id;

EXCLUDE USING gist · 阻止重叠预约

PostgreSQL

这里的临时表代表一个资源。排斥约束用 && 拒绝与现有行重叠的预约。DO NOTHING 跳过冲突，RETURNING 只显示实际写入的预约。空区间不会重叠，实际预订可加 CHECK (NOT isempty(stay))。

唯一表达式索引 · 只约束有效账号

PostgreSQL

索引键是 lower(email)，WHERE 决定哪些行受唯一性约束。一个活跃账号已占用该邮箱时，允许录入停用账号。

generate_series · 生成日期补齐零销量

PostgreSQL

先生成完整日期，再左联结销售记录。COUNT(右侧日期) 对未匹配行返回 0，FILTER 可在同一次分组中单独数已付款。

查看执行前的数据
销售明细
sold_onstatus
2026-06-01paid
2026-06-01pending
2026-06-03paid

执行结果

WITH sales(sold_on, status) AS (VALUES (DATE '2026-06-01', 'paid'), (DATE '2026-06-01', 'pending'), (DATE '2026-06-03', 'paid') ) SELECT DATE '2026-06-01' + offsets.n AS day, COUNT(s.sold_on) AS total, COUNT(*) FILTER (WHERE s.status = 'paid') AS paid FROM generate_series(0, 2) AS offsets(n) LEFT JOIN sales AS s ON s.sold_on = DATE '2026-06-01' + offsets.n GROUP BY offsets.n ORDER BY offsets.n;

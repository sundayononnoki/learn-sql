小写折叠、双引号与保留字

PostgreSQL

裸标识符折叠为小写。双引号保留原拼法，也允许把关键字用作名字。常规对象名可用小写和下划线，引用已有的带引号名称时保持大小写一致。

单引号、E 转义和 Unicode 转义

PostgreSQL

普通字符串用两个单引号表示一个撇号。E 字符串显式识别反斜杠转义。U& 后接引号与 Unicode 码点。示例默认转义符为 \，数据库采用 UTF-8。普通字符串里的反斜杠行为由 standard_conforming_strings 控制，现代默认值为 on。U& 字符串字面量要求 standard_conforming_strings 为 on。

美元引号保留字符串正文

DATE、TIME 与 INTERVAL 字面量

PostgreSQL

类型名加字符串可直接声明日期、时刻和间隔。日期加整数按天计算，日期加 interval 返回 timestamp。按日历加月时，目标月天数不足会落在该月的最后一天。

TRUE、FALSE、UNKNOWN 与布尔筛选

PostgreSQL

布尔列可为 TRUE、FALSE 或 NULL。谓词 IS TRUE、IS FALSE 和 IS UNKNOWN 分别识别三种状态，返回确定的布尔值。WHERE 保留条件为 TRUE 的行，排除 FALSE 和 UNKNOWN。

用 IS DISTINCT FROM 比较含 NULL 的新旧值

PostgreSQL

比较两个可空值时，IS DISTINCT FROM 将两个 NULL 视为相同，将一空一非空视为不同。IS NOT DISTINCT FROM 是它的互补谓词。检测字段是否发生变化时可直接使用。

ROW 构造值与多列比较

PostgreSQL

大小比较从左至右看字段。第一对已经分出大小时，后面的 NULL 不参与。如果走到含 NULL 的决定位置，结果为未知。多列游标分页可使用同一方向的行值比较，并按相同的非空列顺序排序。

数组 ANY、SOME 与 ALL

PostgreSQL

ANY 或 SOME 对数组元素逐一比较，存在一个真值就为真。ALL 需要每次比较都为真。空数组的 ANY 为假、ALL 为真。对常见的严格比较符，若没有决定结果且遇到 NULL 元素，就得到未知。

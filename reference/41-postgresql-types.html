PostgreSQL · 内置类型与类型行为

用独立小例子选择列类型，观察取值范围、默认转换和索引行为。除注明版本门槛的写法外，示例以 PostgreSQL 19 的语法为基线。

精确小数、浮点特殊值与 money

PostgreSQLnumeric 的 Infinity 自 PostgreSQL 14 起可用。

numeric 保留十进制精度，real 和 double precision 是近似值。PostgreSQL 排序把 NaN 放在普通数字之后，并视两个 NaN 相等。未约束精度的 numeric 可用正负 Infinity。money 的显示和小数位由 lc_monetary 决定，金额通常以 numeric 和独立的币种列存储。

小整数类型为 smallint、integer、bigint。浮点输入可写 Infinity、-Infinity、NaN。

serial 与 GENERATED AS IDENTITY

PostgreSQLidentity 自 PostgreSQL 10 起可用。

serial 是创建 integer 列、序列及 nextval 默认值的简写。identity 是 SQL 标准列属性，同样通过隐式序列生成值。GENERATED ALWAYS 通常拒绝手写值，BY DEFAULT 可以用显式值覆盖。若要保证唯一，还需 PRIMARY KEY 或 UNIQUE。

uuid、随机 UUID 与按时间排序的 UUID

PostgreSQL

bytea 存原始字节。decode 和 encode 在二进制与可打印文本之间转换。bit(n) 是固定长度的位串，bit varying 允许不同长度。两边为等长位串时，& 按位求与。

PostgreSQL

数组维度、下标与空数组

PostgreSQLcardinality() 自 PostgreSQL 9.4 起可用。

ARRAY 构造数组，二维数组的子数组须同形。普通构造从 1 编号，带显式边界的数组可以采用其他下限，读取时可先查 array_lower。array_length 返回某个维度的长度，cardinality 返回所有维度中的元素总数。

range 与 multirange 表示边界和多段范围

PostgreSQLrange 自 PostgreSQL 9.2 起可用，multirange 自 14 起可用。

左括号 [ 包含下界，右括号 ) 排除上界。离散整数区间可能在储存时变为等价的标准边界形式。multirange 把多个互不相邻且不重叠的连续段表示为一个值。@> 检查包含，&& 检查重叠。

XML、JSON 与 JSONB

PostgreSQLjson 自 PostgreSQL 9.2 起可用，jsonb 自 9.4 起可用。XML 处理要求服务端构建带 libxml。

xml 类型可保存文档或片段。XMLPARSE DOCUMENT 读取文档，XMLSERIALIZE 将其转回文本。json 保存输入的文本形式，jsonb 把结构转换为二进制表示并支持包含查询与索引。重复对象键在 jsonb 中只保存最后一个值。

隐式转换与索引匹配

PostgreSQL

id 为 integer 时，比较 id = '2' 会把未标注类型的字面量推断为整数。把列写成 id::text 则改变了索引键表达式，普通整数索引无法对这个文本条件做等值定位。生产查询宜让参数匹配列类型。确需查转换后的值时可考虑表达式索引。

查看执行前的数据
临时表与对照条件
索引数据条件
PRIMARY KEY (id)编号 1–1000id = '2'；id::text = '2'

执行结果

EXPLAIN (COSTS OFF) SELECT payload FROM ch41_keys WHERE id = '2' UNION ALL SELECT payload FROM ch41_keys WHERE id::text = '2';
QUERY PLAN
Append
-> Index Scan using ch41_keys_pkey on ch41_keys
Index Cond: (id = 2)
-> Seq Scan on ch41_keys ch41_keys_1
Filter: ((id)::text = '2'::text)

这是样例计划。实际计划取决于统计数据、成本设置和 PostgreSQL 版本。关注 Index Cond 与 Filter 的差异。

建立全文索引

MySQL

InnoDB 和 MyISAM 可用 FULLTEXT。索引可在建表时指定，也可用 ALTER TABLE 补建。以下选择 CHAR、VARCHAR 或 TEXT 等受支持的文本列。

过时 · 仅 MyISAM 支持的历史描述 InnoDB 从 MySQL 5.6 起也支持 FULLTEXT。自然语言模式里的 50% 阈值仍是 MyISAM 的规则。InnoDB 手册。

执行前　docs 已有覆盖 title、body 的全文索引。ch18_search 尚未创建。

布尔搜索表达必须、排除、前缀和短语

MySQL

停用词、长度与中文分词

MySQL

默认 InnoDB 分词器跳过停用词和过短的词。中文练习可用 ngram 按连续字符切分。为匹配目标预先选择合适的分词方式。

执行前　默认词长 3、ngram 大小 2。中文样例为 1:订单管理 与 2:笔记整理。

执行结果

数据库、数据库管理系统与表

MySQL

数据库是有组织的数据集合，MySQL 是管理它的数据库管理系统（DBMS）。在 MySQL 中 schema 也指数据库，在建模语境中还可指库表的结构。表名在库内唯一，例如 learn_sql_lab 中的 products 每行存一件商品。

执行前　已选中 learn_sql_lab，其中有商品表。

MySQL

单列主键与组合主键

MySQL

主键唯一标识行，组成主键的每列都要求非 NULL。选一个稳定的标识，例如商品编号。订单明细用订单编号和商品编号的组合，同一个订单可以有多件商品。

SQL 与数据库方言

MySQL

自测

订单 101 有两条商品明细。只用订单编号可以唯一定位其中一条吗？

查看答案

同时指定订单编号和商品编号，就能唯一定位一条明细。

数量为 2。

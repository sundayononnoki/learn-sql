核对三段版本和精确版本

MySQL

mysql --version 显示客户端工具版本。连接后执行 VERSION() 才能确认服务端版本。2026 年 10 月这三条发布线加入 VERSION_WITH_UPDATE()，第四段用于区分同一补丁版本的额外更新。

列内 REFERENCES 的行为变化

MySQL

MySQL 8.4 对列定义内的 REFERENCES 不建立外键。MySQL 9.0 起会建立并强制执行。同一份旧 DDL 升级后重建时，结果可能不同。要兼容 8.4 与新版，用表级 FOREIGN KEY写法。

VECTOR 类型及维度函数

MySQL

从 MySQL 9.0 起可用 VECTOR(n) 保存最多 n 个单精度浮点元素。字符串转换成向量后，可读取维度或转回文本。

检查认证插件与可选组件

MySQL

caching_sha2_password 是当前主流账号认证方式。26.10 将 WebAuthn 插件和 Health Monitor 提供给 Community Edition，并提供服务端 MySQL REST Service 组件。26.7 起 Community Edition 可使用 Thread Pool 插件。部署前要核对组件是否已加载、所在平台及所需权限。

过时内容与替代写法

MySQL

「已弃用」表示当前版本仍可能支持，后续版本可能移除。「已移除」表示对应版本里不能再依赖该功能。原书中的老写法在对应章节保留了醒目标记。

旧写法与迁移入口
旧内容现状当前用法
MySQL Administrator / Query Browser过时 · 工具已停止维护终端 mysql。Workbench 有版本兼容边界
[[:<:]] / [[:>:]] 正则词边界过时 · ICU 不支持用 ICU 的 \b。SQL 字符串按模式转义
BINARY 作为 REGEXP 输入过时 · 新版拒绝二进制正则参数按需求选择 REGEXP_LIKE 的 c 或 i
utf8mb3 / 旧 utf8 别名过时 · 已弃用新库和连接显式使用 utf8mb4
非唯一或部分父键作为外键目标过时 · 已弃用，8.4 起默认拒绝新建引用父表的 PRIMARY KEY 或完整 UNIQUE 键
mysql_native_password 服务端插件过时 · 8.4 默认禁用，9.0 起移除caching_sha2_password
PASSWORD() / 用 GRANT 创建账号过时 · MySQL 8.0 已移除CREATE USER、ALTER USER 后单独 GRANT
mysqlhotcopy过时 · 5.7 发布线已移除mysqldump 或受支持的物理备份工具

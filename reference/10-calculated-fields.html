CONCAT、空白与 NULL

MySQL

用 CONCAT 拼接，LTRIM、RTRIM、TRIM 清理左、右或两侧空格。任一参数是 NULL 时，CONCAT 返回 NULL。可用 COALESCE 代替缺失值。

查看执行前的数据
customers · 相关行
customer_idcity
3NULL

执行结果

SELECT CONCAT(TRIM(' SQL '), ' / ', RTRIM('book ')) AS label, LENGTH(LTRIM(' SQL')) AS letters, CONCAT('城市 ', city) AS raw_label, CONCAT('城市 ', COALESCE(city, '未知')) AS city_label FROM customers WHERE customer_id = 3;
labellettersraw_labelcity_label
SQL / book3NULL城市 未知
执行说明

执行前　两个字符串带空格。客户 3 的 city 为 NULL。

执行后　拼接标签 SQL / book，修剪后长度 3，直接拼城市得 NULL，使用缺省值得 城市 未知。

得到 SQL / book、3、NULL、城市 未知。

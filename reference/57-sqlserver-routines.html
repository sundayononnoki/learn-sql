Service Broker 消息、契约、队列与往返

SQL ServerSQL Server 启用 Service Broker 的库，或所支持的 Azure SQL Managed Instance。本例为同库、单发起会话

在启用了 Service Broker 的独立练习库执行，可先查 sys.databases.is_broker_enabled。契约允许发起者发请求，目标服务把消息放进 dbo.ch57_target_q。接收超时至多 5 秒。若队列没有消息，先查看 sys.transmission_queue 的 transmission_status。交易内 SEND 与 RECEIVE 分别受所在事务提交控制。在独立、自动提交的练习数据库内运行，不复用现有队列。Service Broker 队列需 RECEIVE，开始对话还需相应契约 REFERENCES。

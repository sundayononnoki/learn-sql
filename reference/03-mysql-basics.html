建库

查当前库

PostgreSQL

登录后的账号即可查询。下表对应默认练习连接 postgres 已将 search_path 设为 sql_notes_lab 的会话。

SELECT current_database() AS database_name, current_schema() AS schema_name;查询结果
database_nameschema_name
postgressql_notes_lab

数据库是连接的目标。schema（模式）是数据库内给表分组的命名空间，同一个数据库可有多个 schema。current_schema() 显示搜索路径中首个有效的 schema。新连接可能显示 public，按切库小节设置练习模式。

切库

PostgreSQL

SELECT current_database() AS database_name, current_schema() AS schema_name;查询结果
database_nameschema_name
postgressql_notes_lab

在 psql 中运行第一段，或在系统终端运行第二段打开新会话。系统终端示例默认用本机账号连接。使用其他主机或账号时补 -h 主机 -U 用户。使用图形客户端时，选择目标库后重连。连接成功后在该会话运行第三段设置模式并核对。

托管数据库的连接与 TLS

MySQL

网站后端连托管实例前需要端点、端口、库名和数据库账号。账号最小授权见第 28 章。连接参数里的 --ssl-mode=VERIFY_IDENTITY 配合服务商提供的 CA 文件可以校验证书和主机名。替换下面的主机、账号和 CA 文件路径，再在终端运行。

mysql -h db.example.com -P 3306 -u app_reader -p --ssl-mode=VERIFY_IDENTITY --ssl-ca=/path/to/provider-ca.pem -D learn_sql_lab

取前 N 行与并列

MySQL

先用 ORDER BY 定义「前几行」。需要固定行数时用唯一键打破并列。要保留同价的第一名，只按价格计算 RANK()，再用编号确定展示顺序。

2 · WITH ranked AS ( SELECT product_id, price, RANK() OVER (ORDER BY price DESC) AS price_rank FROM products ) SELECT product_id, price FROM ranked WHERE price_rank = 1 ORDER BY product_id;

同一张 products 表，取按价格降序和编号升序排列的首行
数据库最小写法商品编号
SQL ServerSELECT TOP (1) product_id FROM products ORDER BY price DESC, product_id;2
PostgreSQL / OracleSELECT product_id FROM products ORDER BY price DESC, product_id FETCH FIRST 1 ROW ONLY;2
旧式 OracleSELECT product_id FROM (SELECT product_id FROM products ORDER BY price DESC, product_id) WHERE ROWNUM <= 1;2

SQL Server 的 SELECT TOP (50) PERCENT product_id FROM products ORDER BY price DESC, product_id; 将五件商品的前一半向上取整，返回编号 2、5、1。SQL Server 的 TOP (1) WITH TIES 与 PostgreSQL、Oracle 的 FETCH FIRST 1 ROW WITH TIES 按排序键保留并列。查最高价并列时，让内层排序键只有价格。
